# TU map: address range -> source file

Generated by `tools/gen.py` from the static-init span table (engine_map.md section 6) and the per-TU naming passes
(`tu_naming/*/names.csv`). One row per span between two `_GLOBAL_$I` static-init stubs. Read this before trusting any
early label: about a third of the early (Sly 1 majority-vote) labels were wrong.

Conventions:
- **Label**: the Sly 2 source-file name. Plain = inferred from alphabetical link order plus content (HYPOTHESIS unless the
  row says otherwise; link order is a strong constraint because Sucker Punch linked game files alphabetically).
  `?` = a guess. `tu_XXXXXX (...)` = file name unknown, content in brackets.
- **Early label** = the first-pass Sly 1 counterpart vote in engine_map.md (often wrong; kept for cross-reference).
- **Named** = number of non-trivial functions with a proposed or existing name in the drafts.
- Span ends are off by one stub for TUs with global destructors (CONFLICTS #9): such TUs end with a third stub
  `_GLOBAL_$D` that the span table assigns to the next TU (confirmed for sound 0x1FF398, sw 0x210E90, cm 0x14FAA8,
  memcard 0x1AE130, screen 0x1DE280). The **Notes** column records the corrected start where known.
